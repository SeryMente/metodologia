# Vías adicionales y criterio de priorización

Estos expedientes son anexos de preparación, no beneficios concedidos ni decisiones de infraestructura. No se revalidan por asociación AWS, Google, Microsoft, Vercel, GitHub, NVIDIA, Mem0, Hindsight, Zep, Canva, NLnet o Awesome Foundation: conservan su corte previo y requieren actualización antes de actuar.

## Neon · siguiente vía si existe necesidad real de Postgres

Fuente consultada: https://neon.com/startups . La ruta Self-Funded admite proyectos tempranos/autofinanciados con menos de un millón de dólares de financiación y producto/MVP temprano; publica hasta 1.000 dólares en créditos Neon. La ruta Venture-Backed publica hasta 200.000 combinados Neon/Databricks para condiciones de respaldo/financiación específicas; no es el importe aplicable por defecto a Khora. Expiración publicada: doce meses; después continúa el plan y facturación normal. Confirmar productos/cuenta/cuotas cubiertos y obligaciones antes de aceptar.

Ruta: confirmar necesidad sin migrar → entidad/financiación verdaderas → cuenta y coste regular → aplicar desde página oficial → guardar concesión/límites → configurar control de coste con autorización → verificar utilidad. No se ha inspeccionado el formulario ni declarado elegibilidad individual.

Borrador de caso de uso:

Khora is an early-stage software project that may require a managed PostgreSQL service for structured application records and development workflows. We would consider Neon only if it fits a verified technical requirement and an affordable continuation plan. We are not proposing a database migration solely to consume promotional credits.

## Deepgram · vía condicionada a producto de voz y horizonte real

Fuentes: https://deepgram.com/startup-program y https://deepgram.com/startup-program-terms-of-service . Publica hasta 100.000 dólares, discrecionales, doce meses; requiere constructor/startup temprano, producción o intención de lanzar dentro de seis meses y participación activa. Requiere cuenta y Project ID para aplicar. No crear cuenta por este mandato documental.

Términos: créditos no transferibles y ligados al proyecto, solo Pay As You Go, después de consumir créditos estándar; para desarrollo de producto, **no investigación de competidores**. Concede licencia mundial/perpetua de nombre/web/logo para identificar participación en marketing. Esto requiere revisión del operador. No financiar con estos créditos nuestro benchmark comparativo sin aclaración escrita de uso permitido. No confundir máximo publicado con monto adjudicado.

Ruta: confirmar tarea/fecha real sin imponer lanzamiento → comprobar entidad y derechos de marca → resolver restricción de comparación → autorizar cuenta si falta → preparar solicitud específica → revisar condiciones/envío → verificar concesión/caducidad/costes y datos.

Borrador de caso de uso:

Khora is investigating speech-to-text as a possible product component for preserving and retrieving personal ideas. Any Deepgram usage would need a defined product-development purpose, an approved data policy, and a realistic launch plan. We would not use startup promotional credits for competitor research contrary to the program terms.
