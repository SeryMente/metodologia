### Captura y restauración

El código candidato usa SQLite Online Backup API (`SqliteConnection.BackupDatabase`) hacia un DB staging, `PRAGMA quick_check`, SHA-256 y AES-256-GCM. La DEK del backup se envuelve con DPAPI `CurrentUser`; el paquete se verifica en el mismo contexto, se vacía a disco y se registra después en `backup_points`. La restauración consulta `backup_points.package_path` absoluto dentro de la DB existente, autentica/descifra, coteja SHA, ejecuta `PRAGMA integrity_check` y sustituye DB mediante staging/rollback.

Brecha: el paquete `.ocpbak` no sirve como restore from-zero autónomo, porque la ruta del paquete se almacena en la misma DB que se perdió. `quick_check` del snapshot y `integrity_check` del restore no acreditan por sí solos portabilidad, claves, readiness o continuidad funcional.
