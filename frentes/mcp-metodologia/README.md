Leer primero la fuente normativa única en main (Sam, Metacanon y GOW), después el control y el núcleo. Este README es un índice, no un estado vivo paralelo.

**Separación de dominio:** este OCP no es el OCP Khora MCP en SeryMente/khora. Metodología se orienta a desarrollo/gobernanza y a operación local mediante localhost y/o RDC autorizado; Khora conserva las capacidades propias de la prótesis cognitiva y su superficie pública Vercel. No se comparten controles, secretos ni autorizaciones.

**Estado en main:** el núcleo, control, coordinación bilateral y registro provisional están persistidos. El código/artefacto 0.1.0 reportado en la rama de construcción no está integrado en esta revisión de main; build previo no equivale a instalación EP ni aceptación. FOL1 sigue pendiente de activación y no se asigna folio global.
