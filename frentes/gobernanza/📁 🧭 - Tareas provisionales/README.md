## Naturaleza y límites

Este contenedor agrupa objetos provisionales de persistencia de tarea, cada uno con su directorio y núcleo propio. No son frentes de trabajo independientes ni unidades de una taxonomía ya aprobada. La responsabilidad, sesión y autorización se heredan del OCP padre; no se crean controles, sesiones ni folios independientes.

El registro usa provisionalmente el núcleo mínimo del diseño incubado de Tareas (identificador, enunciado, origen y estado), sin declarar ratificado el estándar v0.2 ni adoptar como vigente el candidato v1.0. Cada ID `GOV-TASK-###` es estable dentro de este registro; no se afirma unicidad global.

**Separación respecto de Tareas:** el directorio existente `ambitos/tareas/` sigue en incubación y no está canonizado en el DUG. Su control conserva como titular `chatgpt-C-TAREAS-INICIO-01-SES-20261028-TA6F31C9`, generación 1. No se ha transferido ni modificado.
