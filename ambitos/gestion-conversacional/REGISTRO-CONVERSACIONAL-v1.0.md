# Registro conversacional · guía operativa v1.0

El contrato normativo reside en [ART-024](../../gobernanza/METAPROMPT-CANONICO-SAMANTHA.html#ART-024). Esta guía concreta el uso de la implementación de este repositorio.

- `conversation_id` es un UUIDv7 propio del registro, asignado una vez y retenido al migrar. No equivale a un ID nativo de ChatGPT.
- `cycle_folio` identifica el ciclo; `<folio>-E` es la entrada literal del operador y `<folio>-S` la salida visible del modelo.
- La tabla central incluye repositorio, frente, último folio y referencia recuperable al diálogo. El título es descriptivo, no identidad.
- Si solo se dispone de un lado del ciclo, se marca incompleto; no se reconstruye el lado ausente.
- Los mensajes auxiliares visibles se conservan separadamente; no se concatenan en la salida final.
- El registro literal y la crónica resumida son capas distintas. Metacanon §28 ya regula la conservación literal, procedencia y evidencia del ciclo sustantivo.
- Cada cambio persistente requiere lectura de vuelta. No se afirma captura completa, sincronización ni un ID nativo que no esté expuesto.
